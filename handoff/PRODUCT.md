# 排一下当前产品约定

这份约定表示截至 2026 年 11 月 16 日当前会话确认的产品设计。正式技术选型尚待确认，现有 HTML 是交互草案。

## 产品与部署

- 产品名“排一下”。供 DE、业务、DS、产品等少量多人协作排期。
- 在一台 Mac 或 Linux 电脑部署，同局域网使用者通过 IP 加端口访问同一页面。
- 轻量、本地数据、容易启动，后续正式实现提供一键启动或部署。
- UI 采用雾面玻璃风格，支持完整日夜主题。所有文字、标签、表格、弹层需在夜间可读。
- 正式实现前必须由用户确认技术方案。不能将本草案的内存认证或 localStorage 当成生产后端。

## 导航与顶栏

- 主导航只有“需求”“设置”。
- 需求页顶部横排子 tab：甘特图、需求池、已归档。
- 设置页顶部横排子 tab：角色权限、字段管理、个性化、操作记录、版本记录。字段管理仅超管可见。
- 需求核心筛选位于子 tab 下方；桌面下 tab 行和筛选行均为 44 像素，窄屏允许自然换行。
- 顶栏右侧顺序：搜索、在线访问人员、当前用户头像、日夜切换。日夜按钮与头像同尺寸。
- 不显示重复大标题，不重复展示当前用户名与姓名字头像。角色在顶栏、头像上仅悬停展示；账号表的角色列正常显示。
- 新增需求在顶栏左侧固定位置，仅甘特图、需求池展示。已归档和设置隐藏新增需求；设置同时隐藏搜索。
- 新增按钮使用 hover glow 的跟随鼠标光晕，深色底与当前配色适配。历史 shiny、pulse 等方案已被替代。

## 账号和权限

- 用户名支持中文，所有文案仅写“用户名”，不写“中文用户名”。初始超管名为张金科。
- 角色为超级管理员、管理员、协作者、只读；未登录访问者为游客只读。
- 开发人必须为已存在的注册账号，管理员也可作为开发人。新需求开发人默认未分配，界面显示“-”。
- 协作者包括业务、DS、产品等，不等同于开发者。
- 角色权限页所有人可见；无权操作时按钮和输入控件置灰。字段管理整个入口仅超管可见。
- 超管可调整用户权限；账号可新建、停用、删除。停用和删除保留历史需求、人员关联和日志，阻止登录，并强制退为游客只读。
- 登录身份需要持久保持，不应每次打开页面重新输入密码。
- 用户修改本人密码时输入当前密码、新密码；超管可重设任意人密码，包括自己。没有忘记密码或自助找回。
- 密码输入具有小眼睛显隐。用户此前还要求超管能查看任意人已保存密码；正式存储采用哈希还是可逆加密仍需要在技术讨论中确认，不能擅自替换需求。

## 需求属性

| 属性 | 规则 |
| --- | --- |
| 需求名 | 必填；首尾无空格，允许英文符号与内部空格，不允许指定中文标点 |
| 优先级 | 必填，默认 P1，可由个人设置新增默认值；P0 红、P1 蓝、P2 深灰 |
| 状态 | 必填，默认待评审；固定为待评审、待开发、开发中、已完成、HOLD |
| PRD 链接 | 必填；可复制、清空，图标上复制下删除，尺寸紧凑且有间隔 |
| 提需人 | 必填，自由人名、称呼或团队名，不要求来自账号；非管理员系登录用户默认本人，管理员不默认 |
| 提需日期 | 必填，默认当天 |
| 业务域 | 可选，从超管维护的枚举选择，允许“-” |
| 需求类型 | 默认常规需求，只能常规需求、数据需求二选一，不存在“-”；个人可设置默认值 |
| 望岳链接 | 选填，需求人力与流程工单地址，位于排期信息 |
| 开发人 | 选填，已有注册账号，默认“-” |
| 开发人天 | 默认 3 个工作日；可空或 0，0 表示待估，存在日期时图上按 3 天占位 |
| 准入日期 | 选填，与开发人天、交付日期联动 |
| 交付日期 | 选填，可编辑，与开发人天双向计算 |
| 项目 | 选填，自由输入，位于补充信息 |
| BRD 链接 | 选填，位于补充信息 |
| 评审日期 | 选填，位于补充信息 |
| 预期交付日期 | 选填，位于补充信息，与实际交付日期分开 |
| 备注 | 选填，可记录 HOLD 原因等 |

另有排期分段、HOLD 间隔、按需求按日的休假和加班标记。

## 新增和编辑面板

- 两者采用相同的右侧滑入覆盖式模态，不挤压主页面。
- 点击遮罩可关闭。新增草稿关闭、刷新、重新打开后保留，提交成功后清空；编辑关闭后丢弃未保存修改，下次读取正式数据。
- 新增和编辑保留三个小 tab：必填信息、排期信息、补充信息。协作者不展示管理员排期字段。
- 必填区域第一行需求名和优先级，第二行短状态框和 PRD 链接，第三行提需人和提需日期。
- 仅管理员系列用户展示可选排期字段：业务域、需求类型、望岳、开发人、人天、准入、交付、分段。
- 管理员和协作者均可使用补充信息：项目、BRD、评审日期、预期交付日期、备注。
- 日期快捷词按昨天、今天、明天等时间顺序排列，点击即可选日。
- 开发人、提需人的最近使用建议独立记录，后缀 X 可删除建议，不互相混入；只有正式提交才增加引用历史。
- 分段按组展示，添加按钮紧凑，段可删除，只有一段时退回普通单段形式。

## 需求池与归档

- 需求池记录全部信息，字段可显隐及调整顺序。优先级以标签放在需求名前，不存在独立优先级列或显示字段选项。
- 显示字段面板内左键立即拖动字段整行重排，无六点把手和上下箭头；顺序、显隐需记忆。
- 业务域、需求类型、状态统一使用语义标签，同值同色，表格、筛选、表单下拉保持一致。
- 需求池右键需求名：编辑、删除、归档。只允许手动归档。
- 归档页布局与需求池一致，不显示状态列，开发人天默认隐藏但可在字段中选。
- 归档需求不得直接修改任何属性。超管字段管理的统一更新可作用于归档需求。
- 双击归档需求打开只读详情，无输入框、保存按钮或信息 tab；基本信息、排期信息、补充信息三段纵向同时展示，链接能打开和复制。
- 归档页右键需求名仅恢复到需求池；恢复后才能正常编辑。

## 筛选与搜索

- 核心顺序为业务域、需求类型、状态、开发人；优先级标签在右。
- 优先级可多选。全选、全不选都表示不筛选；未全选时提供小字“全选”。
- 筛选尽量多选，选中所有值时归一显示“全部”；刷新、重开保持选择。
- 甘特图外显开始和结束日期作为显示日期轴。默认过去 7 日至未来 30 日，手动起始日期记忆。
- 结束日期框悬停后滑出 30D、60D 预设，仅改结束日期；离开容错区域即开始滑回，无额外停留延时。
- 日期行在核心筛选下一行左对齐；需求池、归档的更多筛选与显示字段也位于同一层左侧。更多筛选无项目项。
- 顶栏搜索通常为放大镜，点击后向左展开；空值失焦或点击外部自动收起，有查询时保留筛选效果。设置页不提供搜索。

## 日历、人天与排期

- 一个需求一行，只对应一个开发人。甘特图按开发人分组，共用日期轴。
- 天粒度，以中国法定节假日、周末和调休实际工作日计算，周六调休上班则计入默认开发日。
- 默认不加班。允许手动安排休息日并标记加班；个人请假按需求当天单独标记。
- 开发人天表示所有排期段的开发天数总和，不计段间空档。交付取最后一段结束日。
- 修改人天默认延长或缩短最后一段；手动拉长、缩短某段同步修改人天。
- 修改交付日反算人天，不能早于准入或最后一段开始，也不能得到不大于 0 的有效人天。
- 修改一个需求不自动移动其他需求。更换开发人时可接到新开发人最后一条排期后。
- 多段需手动维护，HOLD 属于段间间隔。普通休息日空档不标成 HOLD，HOLD 仅在存在工作日的相应间隔显示。
- 允许需求并行，不阻止重叠，使用透明背景的细长上下往返箭头连接相邻交叠区域，不改需求本身颜色。

## 甘特图交互

- 当前为连续条形段。跨周末、法定休息日和休假时保留淡化的业务域颜色过渡；休假单元格整体灰底。
- 默认每日宽高近似 27 比 24，轻微横向长方形；需求名列和人员名冻结在左侧。
- 悬停段内显示逐日边界和细交付虚线，选中需求也显示最终交付虚线，包括结束于休息日的情况。
- 今日日期格顶部蓝线，整列半透明色，不使用竖线贯穿作为主要标记。
- 状态为开发中、当前段包含今天、今天实际开发或加班时才显示粒子动效；不表示百分比进度。
- 右键按下移动拖整段，不需长按；原地右键松开打开菜单。只能移动本需求当前段，不与本需求其他段交叠，不移动其他需求。
- 左键拖首尾可改变周期，联动人天。双击需求名才编辑。
- 双击空白日补排期，第二击按住拖动可选连续多日；跳过休息日和休假，邻接合并，否则新段，可覆盖选中 HOLD，联动人天。
- 保留左键框选延长当前段的预览与加号确认，加号在 cell 内，遇其他段或 HOLD 前停止。
- 人员组整行可展开、收起，姓名前有小旋转箭头；提供全部展开、全部收起按钮，组头突出程度适中。
- 标记顺序为待估人天、HOLD、需求并行、加班、休假。
- 工作日右键只有休假或取消休假，休息日只有加班或取消加班；没有独立恢复默认动作。标记本身不改日期、人天。
- 右键当前排期段还可删除此段。剩余段日期保持，准入取第一段，人天合计剩余段，交付取最后一段；删到一段后折回单段；全部删完仅清空准入和交付日期，保留删除前预估。当前原型同时清理被删除段内的日期标记。
- 单击选中，Ctrl 或 Command 跳选，Shift 连选，不外露复选框。
- 只有多选后右键已选需求名才提供顺排预览、按准入日期排序、取消选中，不展示编辑等其他项。
- 按准入日期排序仅调整每个人下选中需求的展示位置，保留未选需求所在位置及全部排期数据，属于视图操作，不记正式变更日志。
- 顺排必须先预览再应用。各开发人独立处理；未选中间需求与前后的衔接和交叠关系保持，无法消除时说明约束，分段空档一起移动。
- Ctrl 或 Command 加滚轮，仅在图表区域缩放；默认比例最大，最小可看约一年。缩小后自动延后可视结束日期、自适应日周月刻度，需求日期不变。
- 非默认比例时在全部展开前出现重置比例；恢复原始格宽及缩放前开始、结束日期。窄屏一年范围允许图内横向滚动。

## 配色和在线用户

- 按业务域分色，同域跨开发人同色；已有域色固定，新增补最大色差空档，避免动态重排旧颜色。
- 超管字段管理维护全局域色。登录用户可在个性化中设置自己的域色覆盖，只对自己有效，个人优先。
- 双击颜色区域打开模态颜色面板，含实际连续排期条预览，无单独更换颜色按钮或“某某的需求颜色”文案。
- 头像有彩色预设和自定义。支持 JPG、PNG、WebP、GIF；GIF 保留动画，不压为静态首帧。
- 在线最多五个展示位；游客合并项也占位。有游客时最多四个直接展示注册用户，注册用户溢出 +N 后以竖线分隔游客 xN。
- +N 悬停仅列额外注册用户，前面头像不移动。没有游客不显示游客 x0。
- 个性化含头像、业务域个人色、默认需求类型、默认优先级、密度、密码操作。没有“减少动效”设置，但尊重系统减少动效。

## 字段管理

- 子 tab 顺序业务域、项目、提需人，默认业务域。
- 状态固定，不纳入维护；开发人仍来自账号，不在这里创建别名。
- 业务域为受控枚举，只能超管在此新增、删除、改全局默认色，无名称合并机制。
- 有需求引用的业务域不能删除，先把相关需求改到其他域或“-”，包括归档需求引用。
- 提需人、项目为自由填写字段，可多选统一到已有或新名字。直接改写全部匹配需求，包含池、归档和所有状态；没有持久别名字典或集合映射。
- 这些正式更新记日志，支持撤回和快照恢复。

## 版本和操作记录

- 两者是全系统公共资料，不按用户各存一份。
- 版本仅手动保存，随机四位编号，含时间和保存人，可删除。可编辑登录用户可保存，管理员系列用户可恢复或撤回。
- 快照包含需求、项目、开发人员资料以及关联业务字段；账号密码与权限不参与回滚。个人显示偏好也不作为公共需求回滚内容。
- 只有正式提交的数据或账号操作写日志，筛选、视图排序、缩放、未提交草稿不记日志。
- 操作记录最多保留最近 200 条，支持分页、输入 1 至 200 的每页行数，页码和行数可恢复。
- 最近 50 条中的可撤回数据变更支持撤回到此动作；包含该动作本身及后续数据变更，确认面板说明范围。账号、密码和权限不撤回。
- 超范围、已撤回、无权限或本身不支持撤回的动作置灰；撤回后保留历史记录并新增撤回日志。

## 原型和正式实现的边界

原型不是正式后端。当前登录和密码只是交互演示，密码值存于预览内存；共享状态使用演示存储。正式实现需提供服务端认证、权限校验、事务、跨用户并发保护、在线状态、真实持久化和本地节假日数据。
