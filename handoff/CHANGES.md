## 最后一批已完成修改

1. 修复初始密码必填 HTML 被拼到显隐按钮属性中，造成代码文字外露的问题；标签和属性分别处理。
2. 归档详情移除信息 tab，基本、排期、补充三组同时可见，依然只读。
3. 字段维护排序为业务域、项目、提需人，默认业务域。
4. GIF 头像保留原文件动画，原有图片类型继续支持。
5. 排期段右键删除：剩余段重新计算人天及最后交付；全删空日期，保留原预估；可撤回。
6. 多选右键增加按准入日期排序，只变已选行展示顺序，未选位置与排期日期不动。
7. 图表 Ctrl/Command 加滚轮缩放到一年，刻度与全年网格适配，自动延后显示结束日期，重置恢复原范围。

## 接续时不要遗漏

- 当前完整 UI 源码是 ui-source.html，而不是 design-cache.zip 中某个名称相似的旧文件。
- 历史测试也有旧断言，不能把测试里的旧需求当成当前验收标准。
- 技术栈还未确认；Rust、React/Vue、SQLite 的方案是下一环节。
- 跨设备资料统一放在仓库 handoff 目录。仓库是 Private，用户已授权同步本会话项目资料。
- 同步设计文件不等于恢复浏览器私有草稿、预览版本、预览日志或 Codex 客户端内部缓存；边界在 START-HERE 与 manifest 中明示。
