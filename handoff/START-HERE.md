# 排一下跨设备交接

当前阶段是 UI 与产品设计。最新一批 UI 修改已经完成并通过检查，下一步是讨论并由用户确认正式技术选型。不要直接开始搭建正式项目。

## 在 Mac 上继续

1. 克隆私有仓库 `https://github.com/BigdataZjk/Gantt`，打开项目目录。
2. 用浏览器打开 `handoff/preview.html`，查看当前草案。该预览已内嵌图标运行库，无需原 Windows 环境或开发服务器。
3. 在 Codex 中打开这个仓库，给新会话发送：

   > 请先阅读 handoff/AGENTS.md、START-HERE.md、PRODUCT.md、CHANGES.md、TECH-OPTIONS.md，并查看 handoff/preview.html。沿用当前已确认的 UI 和产品规则，先与我确认技术选型，再开始正式实现。必要时查阅 conversation.md，不要恢复 archives 中的旧设计。

4. 需要查看历史图片时，把 `attachments.zip` 解压到 `handoff/attachments/`；需要旧 demo 与参考源码时，把 `design-cache.zip` 解压到独立目录。
5. `design-tools.zip` 保留本次使用的设计技能资料、检索数据与脚本。Mac 可使用当前 Codex 已安装的技能；若需要手动安装个人技能，将其中 `frontend-design`、`ui-ux-pro-max` 的目录安装到 Mac 的技能目录，而非沿用 Windows 绝对路径。

## 资料入口

| 文件 | 用途 |
| --- | --- |
| ui-source.html | 当前唯一权威的 UI 草案源文件，含本轮全部已完成修改 |
| preview.html | 可独立打开的离线预览，内嵌运行库 |
| PRODUCT.md | 当前有效的产品规则，覆盖已被多轮讨论修改的需求 |
| CHANGES.md | 关键变更与被替代设计，防止回退到旧需求 |

| conversation.md / conversation.jsonl | 截至导出时的可读用户及助手消息，不包含模型私有推理或系统指令 |
| attachments.zip | 会话内可恢复的用户图片及文件，含路径映射清单 |
| design-cache.zip | 本会话整个可视化目录的归档，含旧 demo、参考页面、辅助代码与验证截图 |

| preview-state-summary.json | 会话可见的预览状态摘要；不是完整业务数据导出 |
| manifest.json / SHA256SUMS | 文件来源、导出边界、遗漏或不可恢复项，以及完整性校验 |

## 恢复范围

这些文件支持在另一台电脑继续同一个项目，不保证 Git 克隆会将 Codex 客户端恢复为原来的聊天窗口。原生会话恢复还取决于 Codex 版本、会话存储和本地路径；官方提供 resume，但它并不是 Git 的功能。

当前演示的浏览器私有状态与 UI 源码是两种资料。筛选、未提交草稿、人工保存的演示版本、演示操作日志和个人上传头像若仅存在原预览的浏览器存储中，不能从可读会话摘要重建其完整内容。本包明确记录这项边界，不能把 preview-state-summary.json 当成完整的 widgetState。离线预览可使用源文件中的示例数据进行交互演示。

正式产品的密码只在当前预览进程内存里演示，没有写入原型持久化状态、版本或日志，因此不进行密码值迁移。

不迁移服务端提示缓存、模型运行中状态、身份令牌或整个用户级 .codex。原始会话文件存在于原机器的 sessions 目录；本仓库提供可读、可审阅的会话导出，不冒充已经验证可直接导入的原生会话数据库。

## 已完成验证

- 初始密码必填标记与显隐按钮不再把 HTML 属性显示为文字；登录、本人改密、超管重设等入口均已检查。
- 归档详情为三段纵向只读展示；字段管理顺序为业务域、项目、提需人。
- GIF 头像保留原始动画字节，刷新后仍可使用，不进入 widgetState。
- 删除中间段、末段、唯一段和撤回已检查；其余需求日期保持不变。
- 多选后按准入日期排序仅改变选中行的展示顺序，未选中行的位置与需求日期保持不变。
- Ctrl 或 Command 加滚轮缩放，支持一年范围、自适应刻度、恢复默认比例及原日期范围。
- 操作记录分页、自定义行数、200 条保留上限、最近第 50 与 51 条的撤回边界已检查。
- 320、736、1060 像素布局及日夜模式已检查；官方预览包装亦已检查，未发现运行错误。
